崩坏 3 · 本地联机包 1.6.3

日常启动：双击 Start.bat，或 Launcher\BH3.Launcher.exe。
点击“启动服务”后，登录器自动运行同包 Server\BH3.Server.exe。
点击“启动游戏”也会自动准备服务；关闭登录器或点击“停止服务”会正常停服。
无需单独打开服务端，也无需在设置中选择服务端路径。

目录：
  Launcher\           原生 Windows 登录器
  Server\             游戏服务器及运行时
  Server\config\      服务端配置
  Server\data\        玩家存档（首次启动创建）
  Launcher\Data\      登录器设置（首次启动创建）

移动或分发时保留整个文件夹，不要只复制登录器 EXE。
升级前先关闭登录器，保留 Server\data、Server\config 和 Launcher\Data。
客户端可以在首页选择 BH3.exe；游戏端口由登录器自动传给服务端。

1.4.0 新增 GM 工具。登录器顶部点击“GM 工具”，自动启动服务并打开独立管理窗口。
  舰长属性：发放金币、水晶、体力，调整舰长等级。
  背包 / 装备：查看已有武器、圣痕和材料。
  发放装备与物品：搜索目录，加入清单，设置数量与等级，批量发放或作为邮件附件。
  女武神：解锁目录内角色，修改已有角色等级、星级与技能。
  补给管理：家园、角色、装备三类本地自定义奖池；设置开关、价格、奖品权重与稀有保底。
  邮件管理：发送正文与附件，查看已读/领取/过期状态，删除本地邮件。
  游戏内：邮件阅读、收藏、附件领取、单抽、十连、补给券购买、抽取记录与概率查询。
