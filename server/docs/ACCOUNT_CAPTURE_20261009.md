# 官方账号数据采集 · 抓包助手1.0.0

## 当前目标

用户反馈本地伤害偏低，要求参考115CN抓包工具，自己登录官方账号后复制游戏数据。当前本地 `LobbyHandlers.Avatars/Equipment` 只构造单个初始女武神和1级武器，尚未提供完整技能与圣痕；不能把官方账号响应直接覆盖为本地单角色状态。
本次先交付可执行的原生采集和自动导出工具，原始官方样本由用户随后提供。未任意修改伤害倍数或已有玩家存档。

## 工程与流程

工程在 `../../capture/`，入口 `../../start-capture.bat`。工具独立于1.3.8登录器/服务端，自带运行时。
按115CN的WinForms流程保留开始、连续分段、结束、历史记录、容量停止及异常恢复；将传输适配为UDP/KCP，增加账号副本与缺项报告。来源清单、使用、格式及限制见 [抓包工程说明](../../capture/README.md)。

用户先退出本地登录器和游戏，再开始采集；官方启动器正常登录，浏览女武神、技能、武器、圣痕及编队，最后结束采集。工具不操作游戏或官方账号。
输出默认在文档目录 `BH3抓包/capture-时间-编号/`。`account-copy.json` 按连接及UID隔离，保留实际收到的响应原文和可解析字段；`account-summary.txt` 说明数量与缺项。
