# 1.5.2 协同者 / 人偶与补给入口

补给入口没有消失的网络请求：实机日志已收到 4703。客户端 `SupplyEntrancePageContext.SetupGacha` 调用任务解锁条件，10009 通关后服务端仍按旧协议发送状态 2，9.1 将其解释为进行中，因而隐藏抽卡卡片，仅显示商店与充值。

## 修复与覆盖

- `MissionStatus.DOING=2`、`FINISH=3`；`CampaignService.Missions` 使用命名枚举。领取后的关闭任务列表保留。没有自动完成任务、追加水晶或重置领奖记录。
- `CompanionService` 接通 2100/2101 库存、2102/2103 同步、2105/2106 碎片解锁与升星、2107/2108 材料经验、2121/2122 碎片兑换、2123/2124 技能升级与快速升级、1742/1743 技能开关。9.1 的 `ElfSkill.is_mask` 为字段 3。旧版补偿没有历史欠账，明确返回已领取，避免空奖励弹窗。
- 20 个已知角色定义、370 个技能定义；持久化等级、阶级、经验、技能等级和屏蔽状态。寻梦者两种外观共用碎片与养成。出战验证接入普通主线、记忆战场、超弦空间；只允许拥有的一个协同者 / 人偶，零占位可保留，非法和重复成员拒绝。
- GM 新增“协同者 / 人偶”页，可发放、修改等级阶级和提升当前阶级技能。角色卡可通过材料、邮件、商店奖励和补给统一解锁，重复角色转 30 碎片（本地规则）。
- 抓包的 48 号协同者补给模板已接入，含实际 9.1 展示路径和 `display_key_elf_card_id`。四种补给为 20 / 44 / 46 / 48；GM 可配置开关、开放期、奖品、权重和保底，支持单抽、十连、补给券、记录、概率、重试回执。已有三种补给的用户配置不被覆盖。

## 配置边界

资源来自只读参考目录与已审阅的账号抓包，文件哈希记录在 `Operations/companion-sources.json`。旧参考表缺少 116 和协同者的新升星表、部分技能费用及兑换资料。缺失行在 `companions.json` 中明确标记 `localRules` / `localFragmentRule`，采用本地成本；180 号只有已捕获的 7 项技能定义，未声称恢复尚未获得的官方高阶技能表。名称缺失时使用 ID，不猜测中文名称。

这是当前资料覆盖下的本地业务链路实现，不能视为官方全部数值、全部隐藏玩法或新版本完整资源复原。第二部 PJMS 世界与战斗、特殊开放世界、低等级深渊及赛季排位等原先未完成项没有因本次修改变为已完成。
