- 神之键：506/507、753—766 已接入真实状态、升级材料、武器条件、同步级别、调律唯一 ID、技能选择/解锁、定时激活及重置。超限/材料不足不部分扣款。九把已捕获神之键以匹配来源的增量导入保留；已有本地神之键不会被覆盖。

- 作战任务：11 项已接入任务，包括登录、午晚间、体力、通关及深渊；凌晨 4 点每日刷新、周一周刷新。任务状态使用 9.1 的 DOING=2/FINISH=3，113 之前先发送 3751/969 缓存，领取后更新进度和钱包。批量领取失败不部分发奖。
