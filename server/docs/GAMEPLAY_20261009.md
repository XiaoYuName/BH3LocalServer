# 1.5.0 普通主线、记忆战场与深渊基础玩法

本版替换原先仅第一章和关闭玩法的响应，提供可保存、可结算的本地流程。它不是“全部主线已复原”：第二部和特殊章节的独立状态机仍需继续实现。

## 已实现

- 主线目录由 15 关扩至 1314 条定义，38 个章节、15 个章节组、230 个篇章/难度奖励组合、61 项关联任务。保留原表等级与前置；其中 836 条普通难度、873 条在 88 级内可达。307 条旧困难/噩梦定义为 99 级，连同其后继共 441 条仍不可达。
- 普通战斗进入、胜负结算、星级奖励、不同难度独立领奖、章节完成状态和 SQLite 重启恢复。逐一走过 873 个可达定义的服务端前置图。这个测试不代表客户端已加载每个场景。
- 关卡专用试用角色、104 项普通关卡剧情书签。试用不授予角色所有权；剧情完成不授予战斗通关。修复奖励圣痕/角色卡误入材料背包，按实际种类发放。
- 记忆战场：38/56/70/81 级四个分区，三组首领共 62 个难度定义；当前分区在周期内固定。支持进入/结束、训练、首领难度前置、角色锁队、每日累计次数、分数上限、分数档奖励、个人成绩和重启保存。星期二 04:00 起计周期，开放六天，下一周重置挑战记录；历史钱包保留。
- 81 级以上超弦空间：本地四区域，进入前置、楼层顺序、分数上限和最佳分数、独立深渊队伍、重启恢复；86002/86003/86004 三项任务通过正常任务接口领取，重试不重复发奖。采用本地一周周期。
- 世界地图增加战场和深渊入口。查询、开始、结算均使用认证会话账号，忽略包头伪造 UID。

## 数据与兼容边界

来源是本机 `LocalServer/千乐铃音_7.0/KianaBH/Resources/ExcelOutput` 与用户 9.1 抓包。参考协议实际标识 `SeaRelWin8.4.0.proto`，不是完整的 9.1 配置。章节组标识和战场首领族使用抓包中的 ID；不导入官方账号通关、排名或领奖状态。

主线 26 章以后的开放世界、章节方舟、往世乐土式章节等，拥有普通 StageData 条目也不代表对应世界任务、实体、剧情触发、养成系统已经实现。第二部章节 ID 100/150/200/300/306 缺少完整配置。用户提供完整 9.1 ExcelOutput 路径后仍需实现对应状态机。

深渊本地配置使用参考赛程 1028、站点 1011–1014、场景 146005/146006/146016/146004；不是抓包官方当前赛程 3575 的复刻。仍未实现低等级量子/迪拉克深渊、赛季升降级/杯数变化、赛季排名奖励、记忆战场扫荡与排名结算。个人排行榜只提供当前账号成绩，没有伪造其他玩家。

结算属于本地客户端报告模式：验证开始记录、前置、角色归属和目录分数上限，不验证实际战斗过程。战场结束协议没有交易 nonce，已结束的紧邻重试可幂等处理；开始新一局后的迟到旧结算不能宣称拥有密码学级防重放保证。
